# Security Policy

## Reporting a Bug or Vulnerability

For non-security problems please open a pull request or contact the maintainers through the `threshold-network` organization.

If you find a security issue, report it privately through GitHub private vulnerability reporting: open the [Security tab](https://github.com/threshold-network/tss-lib/security) of this repository and choose "Report a vulnerability". Do not open a public issue or pull request for it.

Please include notes about the impact of the issue and a walkthrough on how it can be exploited.

Fixes for reported issues follow the process in [docs/release-policy.md](docs/release-policy.md). Issues in the upstream code that this fork shares may also be reported to [`bnb-chain/tss-lib`](https://github.com/bnb-chain/tss-lib).
